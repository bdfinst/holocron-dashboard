# Tech Debt

## Definition

- [Tech Debt](https://en.wikipedia.org/wiki/Technical_debt) is the implied cost of future reworking required when choosing an easy but limited solution instead of a better approach that could take more time.

## Goal of Measuring

- If tech debts are increasing as more code is being committed to projects, then teams need to take action to reduce tech debts.
- If tech debts are decreasing or steady, then the team is in good shape of maintaining their project while they are producing features.

## Tips for Improvement

- Do not let tech debts linger around too long; if the chart shows that tech debts are increasing, plan to pay back tech debts.
- Review tech debts and fix them as needed using tools such as Sonarqube, Fority, Anchor etc.

## Data Source

Data is aggregated from code scanning tools such as Sonarqube, Fortify, Anchor etc.
